# MiniMind 模型架构学习路线

> 按数据流顺序排列，跟着一个 token 从输入到输出走一遍

## 数据流全景

```
token_ids  [batch, seq_len]
    ↓
① Embedding                         → [batch, seq_len, hidden_size]
    ↓
 ┌───────────────── × N 层 ─────────────────┐
 │                                           │
 │  x ─────────────────────┐ (残差1：保存x)  │
 │  ↓                      │                 │
 │  ② RMSNorm              │                 │
 │  ↓                      │                 │
 │  ③ Attention             │                 │
 │    ├─ RoPE (位置编码)    │                 │
 │    ├─ GQA (分组查询)     │                 │
 │    └─ KV Cache (推理)    │                 │
 │  ↓                      │                 │
 │  + ←────────────────────┘ x + Attn(Norm(x))│
 │  ↓                                        │
 │  x'─────────────────────┐ (残差2：保存x') │
 │  ↓                      │                 │
 │  ⑤ RMSNorm              │                 │
 │  ↓                      │                 │
 │  ⑥ FeedForward/MoE      │                 │
 │  ↓                      │                 │
 │  + ←────────────────────┘ x'+ FFN(Norm(x'))│
 │  ↓                                        │
 └────────────────────────────────────────────┘
    ↓
⑧ RMSNorm (最终 norm)
    ↓
⑨ LM Head                          → [batch, seq_len, vocab_size] logits
```

对应代码（`model_minimind.py:186-193`）：
```python
residual = hidden_states                          # 残差1：保存 Norm 前的 x
hidden_states = self.self_attn(
    self.input_layernorm(hidden_states), ...       # Norm → Attention
)
hidden_states += residual                          # x + Attention(Norm(x))

hidden_states = hidden_states + self.mlp(          # 残差2：x' + FFN(Norm(x'))
    self.post_attention_layernorm(hidden_states)   # Norm → FFN
)
```

关键：残差连的是 **Norm 之前的原始输入**，不是 Norm 之后的。这样残差通路上没有任何 Norm，梯度可以无损回传。

### 面试回答策略

**"你做过分布式训练吗？"**

> 我在 MiniMind 项目里用 PyTorch DDP 做过多卡数据并行训练，理解 AllReduce 梯度同步、DistributedSampler 数据分片、混合精度训练的完整流程。对 ZeRO 和 3D 并行的原理有深入了解，知道 ZeRO-1/2/3 分别切分什么、Tensor Parallel 怎么切矩阵、Pipeline Parallel 怎么减少 bubble，但没有亲手用 DeepSpeed 或 Megatron-LM 训过。

**"你训练中遇到过什么问题？"**

准备好讲：
1. 显存 OOM → 调小 batch size + 梯度累积
2. Loss 不下降 → 检查学习率、数据质量
3. Loss NaN → 混合精度的 GradScaler 动态调整
4. 多卡训练挂起 → NCCL 通信超时排查

**整体叙事线**

> "我通过 MiniMind 项目跑通了 64M 模型的完整训练流程，从预训练到 SFT 到 DPO 到 GRPO，每个阶段的 loss 计算、混合精度、梯度累积、DDP 分布式都是手写的，不依赖 Trainer。在这个过程中深入理解了训练工程的核心概念，也学习了业界大模型训练需要的 ZeRO/3D 并行/Flash Attention 等技术。"

## 为什么这个顺序

- 代码文件的定义顺序是依赖顺序（被用的先定义）
- 学习用数据流顺序更直觉：跟着数据走一遍，知道每个组件在哪个位置、吃什么吐什么
- Config 放最后：学完所有组件后再看超参表，每个参数都能对应上具体代码
- Embedding 最简单先热身，RMSNorm 其次，RoPE 和 Attention 是重头戏
