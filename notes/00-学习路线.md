# MiniMind 模型架构学习路线

> 按数据流顺序排列，跟着一个 token 从输入到输出走一遍

## 数据流全景

```
token_ids  [batch, seq_len]
    ↓
① Embedding                         → [batch, seq_len, hidden_size]
    ↓
 ┌───────────────── × N 层 ─────────────────┐
 │                                           │
 │  x ─────────────────────┐ (残差1：保存x)  │
 │  ↓                      │                 │
 │  ② RMSNorm              │                 │
 │  ↓                      │                 │
 │  ③ Attention             │                 │
 │    ├─ RoPE (位置编码)    │                 │
 │    ├─ GQA (分组查询)     │                 │
 │    └─ KV Cache (推理)    │                 │
 │  ↓                      │                 │
 │  + ←────────────────────┘ x + Attn(Norm(x))│
 │  ↓                                        │
 │  x'─────────────────────┐ (残差2：保存x') │
 │  ↓                      │                 │
 │  ⑤ RMSNorm              │                 │
 │  ↓                      │                 │
 │  ⑥ FeedForward/MoE      │                 │
 │  ↓                      │                 │
 │  + ←────────────────────┘ x'+ FFN(Norm(x'))│
 │  ↓                                        │
 └────────────────────────────────────────────┘
    ↓
⑧ RMSNorm (最终 norm)
    ↓
⑨ LM Head                          → [batch, seq_len, vocab_size] logits
```

对应代码（`model_minimind.py:186-193`）：
```python
residual = hidden_states                          # 残差1：保存 Norm 前的 x
hidden_states = self.self_attn(
    self.input_layernorm(hidden_states), ...       # Norm → Attention
)
hidden_states += residual                          # x + Attention(Norm(x))

hidden_states = hidden_states + self.mlp(          # 残差2：x' + FFN(Norm(x'))
    self.post_attention_layernorm(hidden_states)   # Norm → FFN
)
```

关键：残差连的是 **Norm 之前的原始输入**，不是 Norm 之后的。这样残差通路上没有任何 Norm，梯度可以无损回传。

## 为什么这个顺序

- 代码文件的定义顺序是依赖顺序（被用的先定义）
- 学习用数据流顺序更直觉：跟着数据走一遍，知道每个组件在哪个位置、吃什么吐什么
- Config 放最后：学完所有组件后再看超参表，每个参数都能对应上具体代码
- Embedding 最简单先热身，RMSNorm 其次，RoPE 和 Attention 是重头戏
