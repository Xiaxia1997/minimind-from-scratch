## 1. 二维旋转矩阵

在二维平面上，绕原点旋转角度 θ：

```
Rot(θ) = ┌ cosθ  -sinθ ┐
         └ sinθ   cosθ ┘
```

四个关键性质：

| 性质 | 含义 | 为什么重要 |
|------|------|-----------|
| **正交** | Rot(θ)^T = Rot(-θ) | 转置就是反转，RoPE 相对位置推导的基础 |
| **保范** | \|Rot(θ)·x\| = \|x\| | 旋转不改变向量长度，不破坏语义信息 |
| **可组合** | Rot(a) · Rot(b) = Rot(a+b) | 两次旋转等于一次旋转 |
| **关键等式** | Rot(a)^T · Rot(b) = Rot(b-a) | Q·K 点积中绝对位置抵消的数学基础 |

## 2. Givens rotation：高维空间里只转两个坐标

### 2.1 定义

在 n 维空间中，Givens rotation G(i, j, θ) 是：**只在第 i 和第 j 维构成的平面上旋转 θ，其余维度不动。**

矩阵形式：n×n 的单位矩阵，在 (i,i), (i,j), (j,i), (j,j) 四个位置替换为旋转块。

### 2.2 具体例子

6 维空间，只旋转第 0 和第 1 维，G(0, 1, θ)：

```
┌ cosθ  -sinθ   0     0     0     0  ┐ ┌ q0 ┐   ┌ q0·cosθ - q1·sinθ ┐
│ sinθ   cosθ   0     0     0     0  │ │ q1 │   │ q0·sinθ + q1·cosθ │
│  0      0     1     0     0     0  │ │ q2 │ = │ q2（不变）          │
│  0      0     0     1     0     0  │ │ q3 │   │ q3（不变）          │
│  0      0     0     0     1     0  │ │ q4 │   │ q4（不变）          │
└  0      0     0     0     0     1  ┘ └ q5 ┘   └ q5（不变）          ┘
```

只有 q0 和 q1 被旋转，其余完全不动。

## 3. QR 分解与 Givens rotation

### 3.1 QR 分解是什么

把任意矩阵 A 分解为：

```
A = Q · R

Q: 正交矩阵（列向量两两正交，长度为 1）
R: 上三角矩阵
```

用途：求解线性方程组、最小二乘、特征值计算等。

### 3.2 用 Givens rotation 实现 QR 分解

思路：**逐个消去下三角元素**。每次选一个 Givens rotation，精确消去一个下三角位置：

```
原矩阵 A:          经过 G1:          经过 G2:         经过 G3:
┌ a  b  c ┐       ┌ a' b' c' ┐     ┌ a'' b'' c'' ┐   ┌ r₁₁ r₁₂ r₁₃ ┐
│ d  e  f │  G1→  │ 0  e' f' │ G2→ │ 0   e'' f'' │ → │ 0   r₂₂ r₂₃ │ = R
│ g  h  i │       │ g' h' i' │     │ 0   h'' i'' │   │ 0   0   r₃₃ │
  ↑ 消这个           ↑ 消这个          ↑ 消这个

G1 旋转 (0,1) 维，选角度使 d 变成 0
G2 旋转 (0,2) 维，选角度使 g' 变成 0
G3 旋转 (1,2) 维，选角度使 h'' 变成 0

最终: G3 · G2 · G1 · A = R
所以: A = (G1^T · G2^T · G3^T) · R = Q · R
```

每个 Givens rotation 的角度由"要消去哪个元素"决定：`θ = atan2(要消的元素, 对角元素)`。

### 3.3 和 Householder 的对比

QR 分解还有另一种方法——Householder 反射：

| | Givens rotation | Householder 反射 |
|---|---|---|
| 每步操作 | 旋转 2 个维度，消去 1 个元素 | 反射整列，消去整列下三角 |
| 适合场景 | 稀疏矩阵、并行化 | 稠密矩阵、通用 |
| 计算量 | 多次操作，每次便宜 | 少次操作，每次较贵 |

numpy 的 `np.linalg.qr` 默认用 Householder。Givens 在 GPU 并行和稀疏场景更有优势。

## 4. RoPE 的分块对角结构

### 4.1 从 Givens 到分块对角

RoPE 不是用一个 Givens rotation 消元素，而是**把多个不重叠的 Givens rotation 合并为一个分块对角矩阵**：

```
         ┌ Rot(θ₀)                    ┐
         │        Rot(θ₁)             │
R(m) =   │              Rot(θ₂)       │     ← 48 个 2×2 旋转块
         │                    ...     │        对角线上，互不干扰
         └                    Rot(θ₄₇)┘
```

和 QR 分解中 Givens 的区别：

| | QR 分解中的 Givens | RoPE 中的 Givens |
|---|---|---|
| 目的 | 消去矩阵元素 | 编码位置信息 |
| 使用方式 | **串行**，逐个作用 | **并行**，不重叠的对同时旋转 |
| 旋转角度 | 由要消去的元素值决定 | 由 token 位置和频率决定 |
| 维度配对 | 按需选择任意 (i,j) 对 | 固定相邻配对 (0,1), (2,3), ... |

### 4.2 数学定理

**线性代数定理**：任何偶数维的旋转矩阵（SO(n) 中的元素）都可以通过选择合适的基底，分解为分块对角形式——n/2 个互相正交的二维平面，每个平面上独立旋转。

RoPE 直接用相邻维度 (0,1), (2,3), ... 作为这些平面，这是最简单的选择。

### 4.3 为什么分块对角对计算有利

如果构造完整的 96×96 矩阵做矩阵乘：

```
计算量: 96 × 96 = 9216 次乘法
存储: 96 × 96 = 9216 个参数
```

分块对角矩阵每对只需 4 次乘法 + 2 次加法，48 对 = 288 次运算。

代码里更进一步，展开旋转公式为**逐元素运算**：

```python
# 二维旋转展开:
# q0' = q0·cosθ - q1·sinθ
# q1' = q0·sinθ + q1·cosθ
#
# 所有对一起做:
q_embed = q * cos + rotate_half(q) * sin
```

全是逐元素乘法和加法，GPU 上极快，不需要构造任何矩阵。

## 面试中怎么提

这部分不需要主动讲，但如果面试官追问"RoPE 的矩阵结构"：

> "RoPE 的旋转矩阵是分块对角结构——48 个独立的 2×2 旋转块。这是 Givens rotation 的特例，每对维度在一个独立的二维平面上旋转。分块对角的好处是可以展开成逐元素乘法，不需要真正的矩阵乘，计算从 O(d²) 降到 O(d)。"
