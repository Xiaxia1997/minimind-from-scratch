全开源（数据+权重）模型对照与全流程训练建议（10.a，2026-07-21）

> 来源：2026-07-21 网络检索（arXiv + 官方页 + 二手报道），未经本地下载验证，全部标 📄/⚠️
> 背景问题："哪些大模型数据+模型权重都开源了？想从预训练→SFT→RL 全训一遍怎么搞？"

### 全开源名单（数据 + 权重 + 代码）

- **OLMo 3 / 3.1**（AI2，7B/32B，2025-11 发布、12 月更新，[arXiv:2512.13961](https://arxiv.org/abs/2512.13961)）📄——全流程透明度标杆：Dolma 3 预训练数据、mid-training、长上下文、SFT、RL（Tulu 配方 + open-instruct GRPO/RLVR），中间 checkpoint + 训练日志全开，标准 dense 架构，**照着学的首选**
- **SmolLM3**（HF，3B，11T tokens）📄——FineWeb 系数据 + 后训练配方全开，个人复现最友好
- **Marin**（Stanford CRFM，8B）⚠️——Levanter 框架，配方 + 中间 ckpt 全开，定位就是可复现
- **Nemotron 3 家族**（NVIDIA，最新者，见下节）📄
- 其他：LLM360 K2/Amber、Pythia（70M–12B）、MAP-Neo（7B 中英）、DCLM-7B、BLOOM（176B，ROOTS 语料）、Cerebras-GPT、Apertus（瑞士，8B/70B，2025-09）⚠️
- 后训练单点全开：**Tulu 3**（SFT+DPO+RLVR 数据代码全开，base 是 Llama）、**OpenR1**（HF 复现 R1 的 GRPO 流程 + OpenR1-Math 数据）📄

### 最新动态（截至 2026-07-21）

- **最新是 NVIDIA Nemotron 3**：Nano 39B-A3B（2025-12）→ Super 120B-A12B（2026-03，带训练数据集+recipes）→ **Ultra 550B-A55B（2026-06-04）**，混合 Mamba-Transformer + MoE，OpenMDW-1.1 许可可商用 📄
- 但 Nemotron 3 开的是"数据集 + recipes + 权重"，训练日志/中间 ckpt/infra 细节不如 OLMo；架构复杂，复现成本高 ⚠️
- 结论：**论新 = Nemotron 3 Ultra；论学习全流程 = OLMo 3**。Nemotron v3 的后训练数据集可直接拿来练 SFT/RL ⚠️

### 算力账（决定路线的前提）

粗估公式（[10-训练阶段论](10-训练阶段论.md) Part 1.4）：训练时间(秒) = 6 × N_active × T_tokens / (GPU数 × 峰值TFLOPS × MFU)

**预训练：个人基本不碰**

- 7B × 1T tokens，8×A800（MFU=0.4）≈ 50 天 ≈ ¥48,000
- 1B × 50B tokens，8×A800 ≈ 3.5 天 ≈ ¥3,400
- 32B 预训练需要 256+ 卡，个人不现实

**SFT / RL：便宜的多（小时级，几十到几百块）**

### 路线 A：小尺寸全流程复现（0.5–1B）

1. 预训练：FineWeb-Edu / DCLM 数据 + nanotron（HF，教程友好）或 Levanter；先用 Karpathy llm.c/nanoGPT 打底层理解
2. SFT：SmolTalk 或 Tulu-3 混合配方，open-instruct / LLaMA-Factory
3. RL：可验证奖励 GRPO（GSM8K/MATH/代码单测），verl 或 open-instruct RLVR，数据用 OpenR1-Math

费用：1B × 50B tokens 预训练 ~¥3,400（8×A800 3.5 天）；SFT + RL 几十块。总计 ~¥3,500

### 路线 B：站在全开源 base 上训后半段（面试性价比最高，推荐）

- OLMo-3-7B-Base / SmolLM3-Base 出发，自己做 CPT → SFT → RL
- 预训练吃透 OLMo 3 报告（数据清洗/配比/退火/长上下文）能讲清楚即可，亲手训的重点放 SFT+RL——正好是面试最常深挖的
- 与 MiniMind 计划互补：MiniMind 练手全链路，本路线冲 7B

费用：跳过预训练（用开源 base），7B LoRA SFT + DPO ≈ **¥20-50**（公司 V100 免费跑则 ¥0）。全参 GRPO 需租卡 ≈ ¥80-160

### 坑与优先级

- RL 阶段显存/工程要求高 SFT 一个量级（policy + reference + rollout 采样同时驻留），先在 1B 上跑通 verl/TRL 再上 7B
- V100 不支持 BF16，跑 FP16 混合精度需要 GradScaler，NaN/Inf 监控不能省
- 学习价值排序（= 面试考察热度）：数据工程（去重/去污/质量过滤/配比）> RL 稳定性与 reward 设计 > SFT 数据构造 > 预训练 infra
