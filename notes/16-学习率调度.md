# 16 - 学习率调度（Learning Rate Schedule）

> 源码位置：`trainer/trainer_utils.py:40-41`（get_lr 函数）
> 调用位置：`trainer/train_pretrain.py:31-33`

## 一句话总结

MiniMind 用 Cosine Decay 学习率调度：从初始 lr 开始，按余弦函数衰减到 0.1×lr，中间不 warmup。

## MiniMind 的实现

```python
# trainer/trainer_utils.py:40-41
def get_lr(current_step, total_steps, lr):
    return lr * (0.1 + 0.45 * (1 + math.cos(math.pi * current_step / total_steps)))
```

数据流分析：
```
current_step = 0:     lr × (0.1 + 0.45 × (1 + cos(0)))     = lr × (0.1 + 0.9) = lr × 1.0
current_step = T/2:   lr × (0.1 + 0.45 × (1 + cos(π/2)))   = lr × (0.1 + 0.45) = lr × 0.55
current_step = T:     lr × (0.1 + 0.45 × (1 + cos(π)))     = lr × (0.1 + 0)    = lr × 0.1
```

变化曲线：从 lr 平滑衰减到 0.1×lr（不降到 0，保留 10% 的最低学习率）。

```python
# train_pretrain.py:31-33 — 每步手动设置 lr
lr = get_lr(epoch * iters + step, args.epochs * iters, args.learning_rate)
for param_group in optimizer.param_groups:
    param_group['lr'] = lr
```

没有用 `torch.optim.lr_scheduler`，而是手动计算 + 手动赋值。

## MiniMind 简化了什么

### 缺少 Warmup

业界标准做法是**先 warmup 再 cosine decay**：

```
标准:   lr
        ↑
        |    /‾‾‾‾‾‾‾‾\
        |   /            ‾‾‾‾‾‾
        |  /
        | /
        +------------------------→ step
        warmup    cosine decay

MiniMind:  lr
           ↑
           |‾‾‾‾‾‾‾\
           |          ‾‾‾‾‾‾
           +------------------------→ step
           直接从 lr 开始 cosine decay
```

Warmup 的作用：
- 训练初期模型参数是随机的，梯度方向不稳定
- 大学习率 + 不稳定梯度 → loss 爆炸
- 先用小 lr 让模型"热身"，梯度稳定后再加到目标 lr

为什么 MiniMind 能省 warmup？模型只有 64M 参数，训练稳定性问题不大。

### 缺少 min_lr 参数化

MiniMind 硬编码最低 lr = 0.1 × lr。业界通常把 min_lr 作为超参数。

## 业界标准做法

### Cosine Decay with Warmup（LLaMA / GPT 标准）

```python
# 伪代码
def get_lr(step, warmup_steps, total_steps, max_lr, min_lr):
    if step < warmup_steps:
        return max_lr * step / warmup_steps          # 线性 warmup
    else:
        progress = (step - warmup_steps) / (total_steps - warmup_steps)
        return min_lr + 0.5 * (max_lr - min_lr) * (1 + cos(pi * progress))
```

### WSD（Warmup-Stable-Decay）— MiniCPM / DeepSeek 用

```
lr
↑
|     /‾‾‾‾‾‾‾‾‾‾‾‾‾\
|    /                 \
|   /                   \
|  /                     ‾
+-----------------------------→ step
warmup   stable plateau   decay
```

优势：stable 阶段可以随时停止训练并快速 anneal，灵活性更高。

## 超参数参考

## 面试话术

> 学习率调度的标准做法是 Warmup + Cosine Decay：先线性升到目标 lr 让梯度稳定，
> 再按余弦函数衰减到 min_lr。MiniMind 用了简化版的 Cosine Decay，
> 没有 warmup 阶段，直接从 lr 衰减到 0.1×lr。
> 对于 64M 的小模型这样做没问题，但大模型（1B+）不加 warmup 训练初期很容易 loss 爆炸。
> 另一个值得了解的是 DeepSeek 用的 WSD 调度：warmup-stable-decay 三段式，
> stable 阶段保持恒定学习率，好处是可以随时停下来做快速退火，训练灵活性更高。
