# 09c - 反向传播推导：梯度在 Transformer 里怎么流

> 前置：[09-训练基础](09-训练基础.md)（前向 loss 怎么算）、[09a-ML数学基础](09a-ML数学基础.md)（矩阵乘法、链式法则）
> 关联：所有架构篇笔记（01-08）——每个组件的前向过程在这里都有对应的反向推导

## 一句话总结

`loss.backward()` 从 loss 标量出发，沿计算图反向走过 Transformer 每一层，用链式法则算出每个参数的梯度。本章追踪这条梯度流，过 6 个关键节点：Softmax+CE → 线性层 → Attention(QK^T, softmax, PV) → 残差连接 → RMSNorm → SwiGLU。

---

## 前言：反向传播在算什么

前向传播是从输入到 loss：

$$\text{input\_ids} \xrightarrow{\text{Embedding}} h \xrightarrow{\text{8 layers}} h' \xrightarrow{\text{lm\_head}} \text{logits} \xrightarrow{\text{CE}} \text{loss}$$

反向传播从 loss 出发，**逆着计算图**走回去，算出两类梯度：

| 梯度 | 用途 | 流向 |
|------|------|------|
| $\frac{\partial L}{\partial h}$（对中间值的梯度） | 传给前一层继续算 | 一路传到 Embedding |
| $\frac{\partial L}{\partial W}$（对参数的梯度） | 交给 optimizer 更新权重 | 留在当前层 |

每一层做的事都一样：**拿到上游传来的 $\frac{\partial L}{\partial \text{output}}$，算出 $\frac{\partial L}{\partial \text{input}}$ 继续传，顺便算出 $\frac{\partial L}{\partial W}$ 留着更新。** 核心工具就是链式法则。

**维度提示**：以下推导中，MiniMind 的参数为 `hidden_size=768`、`vocab_size=6400`、`n_heads=8`、`head_dim=96`。

## Step 1：Softmax + Cross-Entropy（反向传播的起点）

对应 `scratch/model/model_minimind.py` 的 `MiniMindForCausalLM.forward`：

```python
logits = self.lm_head(hidden_states)          # [B, S, 6400]
x = logits[..., :-1, :].contiguous()          # [B, S-1, 6400]
y = labels[..., 1:].contiguous()              # [B, S-1]
loss = F.cross_entropy(x.view(-1, x.size(-1)), y.view(-1), ignore_index=-100)
```

`F.cross_entropy` 内部做两步——softmax + 负对数似然。先把符号定清楚，再写公式。

### 1.1 符号定义

聚焦**一个位置**（比如序列的第 3 个 token）。模型在这个位置输出一个 logits 向量，长度等于词表大小 $V = 6400$：

$$z = [z_1, z_2, \dots, z_V]$$

$z$ 里的每个分量 $z_k$ 对应词表中第 $k$ 个 token 的未归一化打分（logit）。其中有一个是"正确答案"——假设正确 token 在词表中的 index 是 $c$（比如 token "5" 的 index 是 42，那 $c = 42$），它对应的 logit 就是 $z_c$。

```
具体例子（vocab_size 简化为 5）:

词表:   ["的", "是", "5", "8", "答"]
index:    0     1     2    3     4

模型输出 logits:  z = [1.2, 0.5, 3.1, 0.8, 2.0]
                       z_1  z_2  z_3  z_4  z_5

正确答案是 "5"，index = 2，所以 c = 2
z_c = z_2 = 3.1  ← 正确 token 的 logit
```

后面推导中会出现三个下标，角色各不相同：

| 下标 | 角色 | 含义 |
|------|------|------|
| $c$ | 常数 | 正确 token 的 index（固定值，如 $c = 2$） |
| $i$ | 求导变量 | "对第 $i$ 个 logit 求偏导"——我们想知道 loss 对 $z$ 的每个分量的梯度 |
| $j$ | 求和哑标 | 只出现在 $\sum_j$ 里，遍历词表所有位置，求和完就消失 |

### 1.2 前向：softmax + 负对数似然

softmax 把 logits 变成概率分布——对词表中第 $i$ 个 token：

$$p_i = \frac{e^{z_i}}{\sum_{j=1}^{V} e^{z_j}}$$

分子是第 $i$ 个 logit 的指数，分母是**所有** logit 的指数之和（$j$ 遍历整个词表，求和后 $j$ 就消失了）。

cross-entropy loss 只看正确 token 的概率：

$$L = -\log p_c$$

### 1.3 展开 $L$，消掉分式

把 $p_c$ 的 softmax 定义代入 $L$：

$$L = -\log \frac{e^{z_c}}{\sum_{j} e^{z_j}} = -\log e^{z_c} + \log \sum_{j} e^{z_j} = -z_c + \log \sum_{j} e^{z_j}$$

现在 $L$ 是两项的和：$-z_c$（正确 token 的 logit，取负号）和 $\log \sum_{j} e^{z_j}$（所有 logit 的 LogSumExp）。这个形式对求导更方便——不用处理分式。

### 1.4 求梯度 $\frac{\partial L}{\partial z_i}$

我们要算 loss 对 logits 向量每个分量的偏导——"$z$ 的第 $i$ 个分量动一动，loss 变多少"：

$$\frac{\partial L}{\partial z_i} = \underbrace{-\frac{\partial z_c}{\partial z_i}}_{\text{第一项}} + \underbrace{\frac{\partial}{\partial z_i} \log \sum_{j} e^{z_j}}_{\text{第二项}}$$

**第一项** $-\frac{\partial z_c}{\partial z_i}$：$z_c$ 是 $z$ 向量中位置 $c$ 的那个分量。如果 $i = c$（我们求导的位置恰好就是正确 token），$\frac{\partial z_c}{\partial z_i} = 1$；如果 $i \neq c$（求导的位置不是正确 token），$z_c$ 和 $z_i$ 是独立的分量，导数 $= 0$。所以第一项 $= -\mathbb{1}[i = c]$。

**第二项** $\frac{\partial}{\partial z_i} \log \sum_{j} e^{z_j}$：用链式法则拆成外层和内层：

- 外层：$\log(\cdot)$ 的导数是 $\frac{1}{\cdot}$，即 $\frac{1}{\sum_{j} e^{z_j}}$
- 内层：$\sum_{j} e^{z_j}$ 对 $z_i$ 的导数——求和中只有 $j = i$ 那一项含 $z_i$，导数为 $e^{z_i}$

两者相乘：$\frac{e^{z_i}}{\sum_{j} e^{z_j}} = p_i$（这正好是 softmax 的定义！）

**合起来**：

$$\boxed{\frac{\partial L}{\partial z_i} = p_i - \mathbb{1}[i = c]}$$

- 当 $i = c$（正确 token）：梯度 $= p_c - 1$（负数，推高这个 logit）
- 当 $i \neq c$（错误 token）：梯度 $= p_i$（正数，压低这个 logit）

**向量形式**：$\frac{\partial L}{\partial z} = p - y_{\text{onehot}}$，其中 $p$ 是 softmax 输出的概率向量，$y_{\text{onehot}}$ 是正确 token 的 one-hot 向量。

### 1.5 用具体数字验证

```
vocab_size = 5，正确 token index c = 2

softmax 输出:  p        = [0.10, 0.20, 0.50, 0.15, 0.05]
one-hot:       y_onehot = [0,    0,    1,    0,    0   ]
梯度:          dL/dz    = [0.10, 0.20, -0.50, 0.15, 0.05]
                                        ↑ i=c: p_c - 1 = 0.50 - 1 = -0.50（推高）
                           ↑ i≠c: p_i = 0.10（压低）

如果模型很自信（p_c = 0.99）:
  dL/dz_c = 0.99 - 1 = -0.01   ← 梯度很小，几乎不更新（已经对了）
如果模型很差（p_c = 0.01）:
  dL/dz_c = 0.01 - 1 = -0.99   ← 梯度很大，大力纠正
```

**这个 $\frac{\partial L}{\partial z}$ 就是整条反向传播的第一个梯度**——后面每一层拿到的都是从这里链式传下来的。

## Step 2：线性层（所有 Linear 的通用公式）

MiniMind 有大量线性层：lm_head、QKV 投影（wq/wk/wv）、输出投影（wo）、FFN 的 gate/up/down_proj。它们的反向传播公式**完全一样**。

**前向**：$y = xW^T$（`nn.Linear(in, out, bias=False)` 的计算，$W$ 形状 `[out, in]`）。

已知上游传来 $\frac{\partial L}{\partial y}$，用链式法则：

$$\boxed{\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \cdot W} \qquad \boxed{\frac{\partial L}{\partial W} = \left(\frac{\partial L}{\partial y}\right)^T \cdot x}$$

- 第一个公式：梯度传给前一层（乘的是 $W$，不是 $W^T$——因为前向是乘 $W^T$，反向"撤销"一次转置）
- 第二个公式：参数梯度，交给 optimizer 更新

**以 lm_head 为例**（`nn.Linear(768, 6400, bias=False)`）：

```
前向: logits = h @ W^T         h: [B*S, 768]    W: [6400, 768]    logits: [B*S, 6400]

反向:
  dL/dh = dL/d(logits) @ W    [B*S, 6400] @ [6400, 768] → [B*S, 768]
                               ↑ Step 1 的结果                ↑ 继续传给前面的层

  dL/dW = dL/d(logits)^T @ h   [6400, B*S] @ [B*S, 768] → [6400, 768]
                                ↑ 和 W 同形状，用来更新 lm_head 的权重
```

**记住这个模式**——模型里每个 `nn.Linear` 的反向都是"乘转置矩阵"。后面 QKV 投影、FFN 的线性层全是同一套。

## Step 3：Attention 的反向传播

Attention 是整个模型中反向传播最复杂的部分。前向过程（`scratch/model/model_minimind.py` 手写路径）分三步：

```python
# 3a: Q @ K^T / sqrt(d)
scores = (xq @ xk.transpose(-2, -1)) / math.sqrt(self.head_dim)   # [B,H,S,S]
# 3b: softmax
P = F.softmax(scores.float(), dim=-1)                               # [B,H,S,S]
# 3c: P @ V
output = P @ xv                                                     # [B,H,S,d]
```

反向从 $\frac{\partial L}{\partial O}$（output 的梯度）开始，逆着走三步。

### 3c：通过 $O = P \cdot V$（矩阵乘法的反向）

矩阵乘法的反向和 Step 2 的线性层原理一样——对哪个变量求导，就把另一个变量转置后乘上去：

$$\frac{\partial L}{\partial P} = \frac{\partial L}{\partial O} \cdot V^T \qquad \frac{\partial L}{\partial V} = P^T \cdot \frac{\partial L}{\partial O}$$

```
维度:
  dL/dO: [B, H, S, d=96]

  dL/dP = dL/dO @ V^T       [B,H,S,96] @ [B,H,96,S] → [B,H,S,S]
    直觉: "应该多关注哪个位置、少关注哪个位置"

  dL/dV = P^T @ dL/dO       [B,H,S,S] @ [B,H,S,96] → [B,H,S,96]
    直觉: "每个位置的 value 表示应该怎么调"
```

### 3b：通过 softmax（最复杂的一步）

Attention 的 softmax 是**逐行**做的——scores 矩阵 $[S \times S]$ 的每一行是一个独立的 softmax（每一行代表"一个 query 对所有 key 的注意力分布"）。

聚焦**某一行**来推导。先定义符号：

```
一行的输入（scores 的某一行）:  s = [s_1, s_2, ..., s_S]      ← S 个分数
一行的输出（softmax 后的权重）: P = [P_1, P_2, ..., P_S]      ← S 个概率，和为 1

例子（S=4，即序列长 4）:
  s = [2.1, 0.5, -1.3, 1.8]
  P = softmax(s) = [0.42, 0.08, 0.01, 0.49]
```

下面推导 softmax 的 Jacobian——"$s$ 的第 $j$ 个分量动一动，$P$ 的第 $i$ 个分量变多少"，即 $\frac{\partial P_i}{\partial s_j}$：

| 下标 | 角色 | 含义 |
|------|------|------|
| $i$ | 输出位置 | $P$ 向量中第 $i$ 个分量（被影响的那个） |
| $j$ | 输入位置 | $s$ 向量中第 $j$ 个分量（被扰动的那个） |
| $k$ | 求和哑标 | 只出现在 $\sum_k e^{s_k}$ 里，遍历所有位置后消失 |

**softmax 定义**：$P_i = \frac{e^{s_i}}{\sum_k e^{s_k}}$（分子只含 $s_i$，分母含所有 $s_k$）。

**情况 1：$i = j$**（扰动的位置和被影响的位置是同一个）——分子 $e^{s_i}$ 含 $s_i$，分母 $\sum_k e^{s_k}$ 也含 $s_i$，用商的导数 $\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}$：

$$\frac{\partial P_i}{\partial s_i} = \frac{e^{s_i} \cdot \sum_k e^{s_k} - e^{s_i} \cdot e^{s_i}}{(\sum_k e^{s_k})^2} = \frac{e^{s_i}}{\sum_k e^{s_k}} - \left(\frac{e^{s_i}}{\sum_k e^{s_k}}\right)^2 = P_i - P_i^2 = P_i(1 - P_i)$$

**情况 2：$i \neq j$**（扰动的位置和被影响的位置不同）——分子 $e^{s_i}$ 不含 $s_j$，所以 $f' = 0$；分母对 $s_j$ 的导数是 $e^{s_j}$：

$$\frac{\partial P_i}{\partial s_j} = \frac{0 \cdot \sum_k e^{s_k} - e^{s_i} \cdot e^{s_j}}{(\sum_k e^{s_k})^2} = -\frac{e^{s_i}}{\sum_k e^{s_k}} \cdot \frac{e^{s_j}}{\sum_k e^{s_k}} = -P_i P_j$$

合并两种情况：

$$\boxed{\frac{\partial P_i}{\partial s_j} = P_i(\delta_{ij} - P_j)}$$

其中 $\delta_{ij}$ 是 Kronecker delta（$i = j$ 时为 $1$，否则为 $0$）。代入验证：$i = j$ 时得 $P_i(1 - P_i)$ ✓，$i \neq j$ 时得 $-P_i P_j$ ✓。

**用链式法则算 $\frac{\partial L}{\partial s_i}$**——loss 对 scores 第 $i$ 个分量的梯度。$s_i$ 通过 softmax 影响**所有**输出 $P_1, P_2, \dots, P_S$（因为分母 $\sum_k e^{s_k}$ 含 $s_i$），所以要对所有 $P_j$ 求和：

$$\frac{\partial L}{\partial s_i} = \sum_{j=1}^{S} \frac{\partial L}{\partial P_j} \cdot \frac{\partial P_j}{\partial s_i} = \sum_{j} \frac{\partial L}{\partial P_j} \cdot P_j(\delta_{ji} - P_i)$$

注意这里 Jacobian 的下标是 $\frac{\partial P_j}{\partial s_i}$（输出位置 $j$，输入位置 $i$），代入公式得 $P_j(\delta_{ji} - P_i)$。

展开 $\delta_{ji}$——在整个求和中，只有 $j = i$ 那一项的 $\delta_{ji} = 1$，其余为 $0$：

$$= \frac{\partial L}{\partial P_i} \cdot P_i \cdot (1 - P_i) + \sum_{j \neq i} \frac{\partial L}{\partial P_j} \cdot P_j \cdot (-P_i) = \frac{\partial L}{\partial P_i} \cdot P_i - P_i \sum_{j} \frac{\partial L}{\partial P_j} \cdot P_j$$

记 $\text{dot} = \sum_{j} \frac{\partial L}{\partial P_j} \cdot P_j$（一个标量：上游梯度和 softmax 输出的 element-wise 乘积之和），提取公因子 $P_i$：

$$\frac{\partial L}{\partial s_i} = P_i \left(\frac{\partial L}{\partial P_i} - \text{dot}\right)$$

写成向量形式（对整行同时算）：

$$\boxed{\frac{\partial L}{\partial s} = P \odot \left(\frac{\partial L}{\partial P} - \text{dot}\right)} \qquad \text{其中 } \text{dot} = \sum_{j} \frac{\partial L}{\partial P_j} \cdot P_j$$

$\odot$ 是 element-wise 乘法。对每一行只需要：一个点积 + 一个减法 + 一个 element-wise 乘法。**不需要显式构造 $S \times S$ 的 Jacobian 矩阵**——这是高效实现的关键。

```
维度:
  dL/dP: [B, H, S, S]         ← 从 3c 传来
  P:     [B, H, S, S]         ← 前向保存的 softmax 输出

  dot = (dL/dP * P).sum(dim=-1, keepdim=True)   # [B, H, S, 1]  ← 每行一个标量
  dL/d(scores) = P * (dL/dP - dot)               # [B, H, S, S]
```

**为什么 FlashAttention 在这里重要**：标准实现必须在前向时保存完整的 $P$ 矩阵 $[B, H, S, S]$（用于反向的 3c 和 3b）。$S = 2048$ 时，一个头的 $P$ 就是 $2048 \times 2048 = 4M$ 个浮点数。8 个头 × $B$ 个 batch → 显存爆炸。FlashAttention 不存 $P$，反向时从 $Q, K$ 重新算——用计算换显存。

### 3a：通过 $\text{scores} = \frac{Q \cdot K^T}{\sqrt{d}}$

已知 $\frac{\partial L}{\partial \text{scores}}$（从 3b 传来），scaling factor $\frac{1}{\sqrt{d}}$ 是常数，直接穿过去：

$$\frac{\partial L}{\partial Q} = \frac{1}{\sqrt{d}} \cdot \frac{\partial L}{\partial \text{scores}} \cdot K \qquad \frac{\partial L}{\partial K} = \frac{1}{\sqrt{d}} \cdot \left(\frac{\partial L}{\partial \text{scores}}\right)^T \cdot Q$$

```
维度:
  dL/d(scores): [B, H, S, S]

  dL/dQ = (1/sqrt(96)) × dL/d(scores) @ K    [B,H,S,S] @ [B,H,S,96] → [B,H,S,96]
  dL/dK = (1/sqrt(96)) × dL/d(scores)^T @ Q  [B,H,S,S] @ [B,H,S,96] → [B,H,S,96]
```

然后 $\frac{\partial L}{\partial Q}$、$\frac{\partial L}{\partial K}$、$\frac{\partial L}{\partial V}$ 分别通过各自的线性投影层（wq、wk、wv）继续反传——又回到 Step 2 的线性层公式。

## Step 4：残差连接（梯度不消失的关键）

`scratch/model/model_minimind.py` 的 `MiniMindBlock.forward`：

```python
residual = hidden_states
hidden_states = self.self_attn(self.input_layernorm(hidden_states), ...)
hidden_states = hidden_states + residual     # 残差连接
```

前向：$y = x + F(x)$（$F$ 是 RMSNorm + Attention 子层）。

反向：

$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \cdot \frac{\partial y}{\partial x} = \frac{\partial L}{\partial y} \cdot \left(\underbrace{1}_{\text{恒等路径}} + \underbrace{\frac{\partial F}{\partial x}}_{\text{子层路径}}\right) = \underbrace{\frac{\partial L}{\partial y}}_{\text{直通}} + \underbrace{\frac{\partial L}{\partial y} \cdot \frac{\partial F}{\partial x}}_{\text{经过子层}}$$

**核心性质**：就算 $\frac{\partial F}{\partial x} \to 0$（子层梯度消失），$\frac{\partial L}{\partial x}$ 仍然等于 $\frac{\partial L}{\partial y}$——梯度原封不动地通过。

MiniMind 有 8 层 Block，每层 2 个残差（Attention + FFN），共 16 条直通路径。梯度从 loss 到 Embedding 可以完全不经过任何非线性变换直接到达：

```
loss → lm_head → norm → [Block 7: FFN残差 → Attn残差] → ... → [Block 0: FFN残差 → Attn残差] → Embedding
                          ↑ 直通       ↑ 直通                     ↑ 直通       ↑ 直通

即使所有子层的梯度都消失了，还有一条从 loss 直达 Embedding 的高速公路
```

这就是为什么 Transformer 可以堆几十甚至上百层而不会出现梯度消失——ResNet 的核心贡献，Transformer 直接继承了。

## Step 5：RMSNorm 的反向传播

`scratch/model/model_minimind.py` 的 `RMSNorm`：

```python
def norm(self, x):
    return x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + self.eps)

def forward(self, x):
    return (self.weight * self.norm(x.float())).type_as(x)
```

聚焦**单个向量** $x = [x_1, \dots, x_d]$（$d = 768$）来推导。先定义符号：

| 符号 | 含义 |
|------|------|
| $x_i$ | 输入向量的第 $i$ 个分量 |
| $\hat{x}_i$ | 归一化后的第 $i$ 个分量（$= x_i / \text{rms}$） |
| $w_i$ | RMSNorm 的可学习 weight 参数的第 $i$ 个分量 |
| $y_i$ | 输出的第 $i$ 个分量（$= w_i \cdot \hat{x}_i$） |
| $i$ | 输出位置（和 Step 3b 一样：被影响的那个分量） |
| $j$ | 输入位置（被扰动的那个分量——"$x_j$ 动一动，$\hat{x}_i$ 变多少"） |

前向三步：

$$\text{rms} = \sqrt{\frac{1}{d}\sum_{k=1}^{d} x_k^2 + \epsilon} \qquad \hat{x}_i = \frac{x_i}{\text{rms}} \qquad y_i = w_i \cdot \hat{x}_i$$

### 5.1 归一化部分的 Jacobian $\frac{\partial \hat{x}_i}{\partial x_j}$

$\hat{x}_i = x_i \cdot \text{rms}^{-1}$ 是两个因子的乘积。关键：**两个因子都可能依赖 $x_j$**——$x_i$ 在 $j = i$ 时直接依赖；rms 通过求和 $\sum_k x_k^2$ **永远**依赖 $x_j$。用乘法法则（$(fg)' = f'g + fg'$）：

$$\frac{\partial \hat{x}_i}{\partial x_j} = \underbrace{\frac{\partial x_i}{\partial x_j}}_{= \delta_{ij}} \cdot \text{rms}^{-1} + x_i \cdot \underbrace{\frac{\partial(\text{rms}^{-1})}{\partial x_j}}_{\text{需要展开}}$$

展开第二项——链式法则拆两层：

$$\frac{\partial(\text{rms}^{-1})}{\partial x_j} = -\text{rms}^{-2} \cdot \frac{\partial \text{rms}}{\partial x_j}$$

$$\frac{\partial \text{rms}}{\partial x_j} = \frac{\partial}{\partial x_j}\sqrt{\frac{1}{d}\sum_k x_k^2 + \epsilon} = \frac{1}{2\text{rms}} \cdot \frac{2x_j}{d} = \frac{x_j}{d \cdot \text{rms}}$$

合起来：$\frac{\partial(\text{rms}^{-1})}{\partial x_j} = -\frac{x_j}{d \cdot \text{rms}^3}$

代回乘法法则：

$$\boxed{\frac{\partial \hat{x}_i}{\partial x_j} = \frac{\delta_{ij}}{\text{rms}} - \frac{x_i x_j}{d \cdot \text{rms}^3}}$$

第一项：只在 $i = j$ 时存在（直接影响）。第二项：对所有 $i, j$ 都存在（通过 rms 间接影响）。

### 5.2 用链式法则算 $\frac{\partial L}{\partial x}$

记 $g_i = \frac{\partial L}{\partial y_i} \cdot w_i$（上游梯度乘以 weight，称为"pre-gradient"——先把 weight 吸收进来简化后续公式），则：

$$\frac{\partial L}{\partial x_j} = \sum_{i=1}^{d} g_i \cdot \frac{\partial \hat{x}_i}{\partial x_j} = \sum_i g_i \left(\frac{\delta_{ij}}{\text{rms}} - \frac{x_i x_j}{d \cdot \text{rms}^3}\right)$$

拆成两项：

$$= \frac{g_j}{\text{rms}} - \frac{x_j}{d \cdot \text{rms}^3} \underbrace{\sum_i g_i x_i}_{\langle g, x \rangle}$$

提取公因子 $\frac{1}{\text{rms}}$，并把 $x_j / \text{rms}^2$ 写成 $\hat{x}_j / \text{rms}$（因为 $\hat{x}_j = x_j / \text{rms}$）：

$$= \frac{1}{\text{rms}} \left(g_j - \frac{\hat{x}_j}{\text{rms}} \cdot \frac{\langle g, x \rangle}{d}\right) = \frac{1}{\text{rms}} \left(g_j - \hat{x}_j \cdot \frac{\langle g, \hat{x} \rangle}{d}\right)$$

最后一步用了 $\frac{\langle g, x \rangle}{\text{rms}} = \left\langle g, \frac{x}{\text{rms}} \right\rangle = \langle g, \hat{x} \rangle$。

向量化形式：

$$\boxed{\frac{\partial L}{\partial x} = \frac{1}{\text{rms}}\left(g - \hat{x} \cdot \frac{\langle g, \hat{x} \rangle}{d}\right)}$$

直觉：取 pre-gradient $g$，减去它在 $\hat{x}$ 方向上的投影（缩放 $\frac{1}{d}$），再除以 rms。减去投影保证输出停留在归一化流形上——和 LayerNorm 的反向传播结构类似。

### 5.3 weight 的梯度

$$\frac{\partial L}{\partial w_i} = \frac{\partial L}{\partial y_i} \cdot \hat{x}_i$$

对 batch 和序列维度求和后，就是 weight 参数的梯度。

## Step 6：SwiGLU（FeedForward）的反向传播

`scratch/model/model_minimind.py` 的 `FeedForward`：

```python
def forward(self, x):
    return self.down_proj(F.silu(self.gate_proj(x)) * self.up_proj(x))
```

前向是**双路径**结构：

```
x ─── gate_proj(x) = g ─── silu(g) = s ───┐
 \                                          × ─── h ─── down_proj(h) = y
  └── up_proj(x) = u ─────────────────────┘
```

反向从 $\frac{\partial L}{\partial y}$ 开始，逆着走 4 步：

**第 1 步：通过 down_proj**（$y = h W_{\text{down}}^T$，Step 2 的线性层公式）：

$$\frac{\partial L}{\partial h} = \frac{\partial L}{\partial y} \cdot W_{\text{down}}$$

```
维度: dL/dy [B,S,768] @ W_down [768, 2432] → dL/dh [B,S,2432]
```

**第 2 步：通过 element-wise 乘法**（$h = s \odot u$）：

$$\frac{\partial L}{\partial s} = \frac{\partial L}{\partial h} \odot u \qquad \frac{\partial L}{\partial u} = \frac{\partial L}{\partial h} \odot s$$

element-wise 乘法的导数：对 $s$ 求导，系数就是 $u$；反之亦然。

**第 3 步：通过 SiLU 激活函数**（$s = \text{silu}(g) = g \cdot \sigma(g)$）：

SiLU 的导数（乘法法则 + sigmoid 导数 $\sigma' = \sigma(1-\sigma)$）：

$$\text{silu}'(g) = \sigma(g) + g \cdot \sigma(g)(1 - \sigma(g)) = \sigma(g)\big(1 + g(1 - \sigma(g))\big)$$

$$\frac{\partial L}{\partial g} = \frac{\partial L}{\partial s} \odot \text{silu}'(g)$$

SiLU 在 $g < 0$ 时导数不为零（不像 ReLU 直接截断），这避免了"dying neuron"问题。

**第 4 步：两条路径汇合回 $x$**（经过 gate_proj 和 up_proj 两个线性层）：

$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial g} \cdot W_{\text{gate}} + \frac{\partial L}{\partial u} \cdot W_{\text{up}}$$

```
维度:
  dL/dg @ W_gate  [B,S,2432] @ [2432,768] → [B,S,768]    ← gate 路径的贡献
  dL/du @ W_up    [B,S,2432] @ [2432,768] → [B,S,768]    ← up 路径的贡献
  两者相加 → dL/dx [B,S,768]
```

**双路径的好处**：$\frac{\partial L}{\partial x}$ 同时从 gate 和 up 两条路拿到梯度。即使一条路的梯度很小，另一条还能提供信号。对比单路径 FFN（如 $\text{ReLU}(xW_1)W_2$），ReLU 会把负区间的梯度完全截断；SwiGLU 的双路径 + SiLU 不存在这个问题。

## SFT 和 RL 的反向传播对比

这条完整的反向路径，**SFT 和 RL 走的是同一条路**。唯一的区别在起点——Step 1 之前 loss 怎么构造：

```
SFT:
  loss = -(log_prob_0 × 1 + log_prob_1 × 1 + ... + log_prob_T × 1) / N
                        ↑ 权重全是 1（每个标准答案 token 一视同仁）
  从这个 loss 出发 → Step 1 → Step 2 → ... → 和上面完全一样

REINFORCE:
  loss = -(log_prob_0 × R + log_prob_1 × R + ... + log_prob_T × R) / N
                        ↑ 权重全是同一个 R(τ)（整条回复的 reward）
  从这个 loss 出发 → Step 1 → Step 2 → ... → 完全一样

PPO:
  loss = -(ratio_0 × A_0 + ratio_1 × A_1 + ... + ratio_T × A_T) / N
                     ↑ 权重是 per-token 的 advantage
  从这个 loss 出发 → 链式法则往回走 → 完全一样
```

**构造 loss 的方式不同 → loss 的数值不同 → Step 1 的 $\frac{\partial L}{\partial z}$ 不同 → 一路传下去每个参数的梯度不同 → optimizer 更新的方向和幅度不同。但反向传播的机制（链式法则 + 矩阵乘转置 + softmax Jacobian + ...）完全一样。**

## 面试话术

> **30 秒版**：反向传播从 loss 标量出发，用链式法则逆着计算图走。起点是 softmax + cross-entropy 的梯度 $p - y_{\text{onehot}}$，非常优雅——就是预测概率减去真实标签。然后通过线性层时乘转置权重矩阵；通过 attention 的 softmax 时需要算 Jacobian，但可以用一个点积 + element-wise 操作高效完成，不用存完整的 $S \times S$ Jacobian；残差连接提供了一条恒等路径，保证梯度不消失；SwiGLU 的双路径让梯度从 gate 和 up 两个方向汇合。SFT 和 RL 的反向传播机制完全一样，区别只在 loss 构造时每个 token 乘的权重——SFT 全是 1，REINFORCE 全是同一个 reward，PPO 用 per-token 的 advantage。

> **追问"FlashAttention 为什么省显存"**：标准 attention 的反向传播需要前向保存的 $P$ 矩阵（softmax 输出），$P$ 的形状是 $[B, H, S, S]$，序列长度 $S$ 一大就爆显存。FlashAttention 不存 $P$，反向时从 $Q, K$ 重新算——用额外计算换显存。这也是为什么 SDPA（`F.scaled_dot_product_attention`）在训练时是首选路径。
