## Part 1：内积、外积、矩阵乘法 ⬜

### 1.1 从矩阵乘法说起

矩阵乘法 $C = A \times B$，规则是"左行 × 右列，对应相乘再求和"：

$$A_{[2,3]} \times B_{[3,2]} = C_{[2,2]}$$

```
A = [1  2  3]     B = [7  10]
    [4  5  6]         [8  11]
                      [9  12]

C[0,0] = 1×7 + 2×8 + 3×9  = 50
C[0,1] = 1×10 + 2×11 + 3×12 = 68
C[1,0] = 4×7 + 5×8 + 6×9  = 122
C[1,1] = 4×10 + 5×11 + 6×12 = 167

C = [50   68]
    [122 167]
```

这个"对应相乘再求和"的操作，有个专门的名字——**内积**。

### 1.2 内积（Inner Product / Dot Product）

两个**等长**向量 → **一个标量**。

$$\vec{a} \cdot \vec{b} = \sum_{i} a_i \times b_i$$

```
a = [1, 2, 3]
b = [7, 8, 9]

内积 = 1×7 + 2×8 + 3×9 = 7 + 16 + 27 = 50
```

符号写法：$\vec{a} \cdot \vec{b}$，或 $\langle a, b \rangle$，或 $a^T b$。

**矩阵乘法的每个格子就是一次内积：** $C[i,j]$ = A 的第 $i$ 行和 B 的第 $j$ 列做内积。

```
C[0,0] = A的第0行 · B的第0列 = [1,2,3] · [7,8,9] = 50   ← 就是内积！
C[0,1] = A的第0行 · B的第1列 = [1,2,3] · [10,11,12] = 68
...
```

所以：**矩阵乘法 = 把所有"行×列"的内积排成一张表**。

### 1.3 外积（Outer Product）

两个向量（**不要求等长**）→ **一个矩阵**。

$$(\vec{a} \otimes \vec{b})_{ij} = a_i \times b_j$$

规则比内积更简单——不求和，直接把每对元素的乘积摆进矩阵：

```
a = [1, 2, 3]     ← 长度 3
b = [4, 5]         ← 长度 2

外积：a 的每个元素 × b 的每个元素

         b[0]=4   b[1]=5
a[0]=1 [ 1×4=4    1×5=5  ]
a[1]=2 [ 2×4=8    2×5=10 ]
a[2]=3 [ 3×4=12   3×5=15 ]

结果: [3, 2] 的矩阵
```

符号写法：$\vec{a} \otimes \vec{b}$，或 $a b^T$。

### 1.4 三者对比

| | 内积 $\vec{a} \cdot \vec{b}$ | 外积 $\vec{a} \otimes \vec{b}$ | 矩阵乘法 $A \times B$ |
|---|---|---|---|
| 输入 | 两个等长向量 | 两个向量（可不等长）| 两个矩阵（内维匹配）|
| 输出 | 标量（1个数）| 矩阵 | 矩阵 |
| 核心操作 | 对应乘，**求和** | 每对乘，**不求和** | 每个格子做一次内积 |
| 要求 | len(a) == len(b) | 无要求 | A 的列数 == B 的行数 |

**关系链：**

```
内积：两个向量 → 一个数（乘了加）
矩阵乘法：一堆内积排成表
外积：两个向量 → 一个矩阵（只乘不加）
```

### 1.5 外积是矩阵乘法的特例

把向量 $a$ 看成 $[n, 1]$ 的列矩阵，$b$ 看成 $[1, m]$ 的行矩阵：

$$a \times b^T = [n, 1] \times [1, m] = [n, m]$$

```
a 竖过来:     b 横过来:
[1]           [4, 5]
[2]    ×
[3]

= [1×4  1×5]     [4   5]
  [2×4  2×5]  =  [8  10]
  [3×4  3×5]     [12  15]

[3,1] × [1,2] = [3,2]    ← 矩阵乘法规则，但结果就是外积
```

所以外积 $= a b^T$，是矩阵乘法在"两个向量"上的特殊情况。

### 1.6 内积和外积的意义——什么时候用？

**内积的意义：衡量两个向量有多"像"（相似度）**

```
a = [1, 0, 0]     b = [1, 0, 0]     → 内积 = 1    完全同向，最像
a = [1, 0, 0]     b = [0, 1, 0]     → 内积 = 0    正交，没关系
a = [1, 0, 0]     b = [-1, 0, 0]    → 内积 = -1   完全反向，最不像
```

在 LLM 中到处都是内积：

| 场景 | 做的事 | 本质 |
|------|--------|------|
| Attention 的 Q·K | query 和每个 key 算相关性 | 内积 = 相似度打分 |
| LM Head 的 h @ W.T | hidden state 和每个 token 向量算相似度 | 内积 = "像哪个 token" |
| 余弦相似度 | cosine_sim = (a·b) / (\|a\|\|b\|) | 归一化的内积 |

**外积的意义：生成两组值的完整组合表（不求和）**

```
用户偏好 = [0.8, 0.2, 0.5]    ← 3 个维度
商品特征 = [0.6, 0.9]         ← 2 个维度

外积 → [3, 2] 的交叉矩阵，每个格子 = "用户维度 i × 商品维度 j"
```

| 场景 | 做的事 | 本质 |
|------|--------|------|
| RoPE 角度表 | 位置 × 频率 → 角度矩阵 | 外积 = 两两配对 |
| 特征交叉 | 用户向量 × 物品向量 → 交互特征 | 外积 = 组合 |
| 概率联合分布 | P(天气) × P(温度) → 联合概率表 | 外积 = 独立事件组合 |

**一句话区分：内积问"有多像"（压缩成一个数），外积问"怎么组合"（展开成一张表）。**

### 1.7 PyTorch 对应

```python
import torch

a = torch.tensor([1., 2., 3.])
b = torch.tensor([4., 5.])

# 内积（要求等长）
torch.dot(a, a)              # tensor(14.)  = 1+4+9
# 或 a @ a

# 外积
torch.outer(a, b)            # tensor([[ 4,  5],
                              #         [ 8, 10],
                              #         [12, 15]])
# 等价写法
a.unsqueeze(1) * b.unsqueeze(0)   # [3,1] * [1,2] → broadcast → [3,2]
a.view(-1, 1) @ b.view(1, -1)     # [3,1] @ [1,2] → matmul → [3,2]

# 矩阵乘法
A = torch.randn(2, 3)
B = torch.randn(3, 2)
A @ B                        # [2,3] @ [3,2] = [2,2]
```

### 1.7 在 RoPE 中的用途

`torch.outer` 在 RoPE 里用来算角度表——32768 个位置 × 48 个频率，需要"每个位置 × 每个频率"的完整组合：

```python
t     = torch.arange(32768)       # [32768]  位置: 0, 1, 2, ..., 32767
freqs = 1.0 / (base ** (...))     # [48]     频率: ω₀, ω₁, ..., ω₄₇

torch.outer(t, freqs)             # [32768, 48]
# 第 m 行第 i 列 = m × ω_i = 位置 m 在第 i 对维度上的旋转角度
```

这就是外积的典型场景：**两组值要两两配对相乘，不求和，铺成一张表**。

## Part 2：旋转矩阵与 Givens 分解 ⬜

> 不影响理解 RoPE 主线，但能帮助理解"为什么 96 维旋转可以拆成 48 个二维旋转"以及代码为什么可以用逐元素乘法实现。

### 2.1 二维旋转矩阵

在二维平面上，绕原点旋转角度 θ：

```
Rot(θ) = ┌ cosθ  -sinθ ┐
         └ sinθ   cosθ ┘
```

四个关键性质：

| 性质 | 含义 | 为什么重要 |
|------|------|-----------|
| **正交** | Rot(θ)^T = Rot(-θ) | 转置就是反转，RoPE 相对位置推导的基础 |
| **保范** | \|Rot(θ)·x\| = \|x\| | 旋转不改变向量长度，不破坏语义信息 |
| **可组合** | Rot(a) · Rot(b) = Rot(a+b) | 两次旋转等于一次旋转 |
| **关键等式** | Rot(a)^T · Rot(b) = Rot(b-a) | Q·K 点积中绝对位置抵消的数学基础 |

### 2.2 Givens rotation：高维空间里只转两个坐标

在 n 维空间中，Givens rotation G(i, j, θ) 是：**只在第 i 和第 j 维构成的平面上旋转 θ，其余维度不动。**

矩阵形式：n×n 的单位矩阵，在 (i,i), (i,j), (j,i), (j,j) 四个位置替换为旋转块。

6 维空间，只旋转第 0 和第 1 维，G(0, 1, θ)：

```
┌ cosθ  -sinθ   0     0     0     0  ┐ ┌ q0 ┐   ┌ q0·cosθ - q1·sinθ ┐
│ sinθ   cosθ   0     0     0     0  │ │ q1 │   │ q0·sinθ + q1·cosθ │
│  0      0     1     0     0     0  │ │ q2 │ = │ q2（不变）          │
│  0      0     0     1     0     0  │ │ q3 │   │ q3（不变）          │
│  0      0     0     0     1     0  │ │ q4 │   │ q4（不变）          │
└  0      0     0     0     0     1  ┘ └ q5 ┘   └ q5（不变）          ┘
```

只有 q0 和 q1 被旋转，其余完全不动。

### 2.3 QR 分解与 Givens rotation

**QR 分解**把任意矩阵 A 分解为：

```
A = Q · R

Q: 正交矩阵（列向量两两正交，长度为 1）
R: 上三角矩阵
```

用途：求解线性方程组、最小二乘、特征值计算等。

用 Givens rotation 实现 QR 分解的思路：**逐个消去下三角元素**。每次选一个 Givens rotation，精确消去一个下三角位置：

```
原矩阵 A:          经过 G1:          经过 G2:         经过 G3:
┌ a  b  c ┐       ┌ a' b' c' ┐     ┌ a'' b'' c'' ┐   ┌ r₁₁ r₁₂ r₁₃ ┐
│ d  e  f │  G1→  │ 0  e' f' │ G2→ │ 0   e'' f'' │ → │ 0   r₂₂ r₂₃ │ = R
│ g  h  i │       │ g' h' i' │     │ 0   h'' i'' │   │ 0   0   r₃₃ │
  ↑ 消这个           ↑ 消这个          ↑ 消这个

G1 旋转 (0,1) 维，选角度使 d 变成 0
G2 旋转 (0,2) 维，选角度使 g' 变成 0
G3 旋转 (1,2) 维，选角度使 h'' 变成 0

最终: G3 · G2 · G1 · A = R
所以: A = (G1^T · G2^T · G3^T) · R = Q · R
```

每个 Givens rotation 的角度由"要消去哪个元素"决定：`θ = atan2(要消的元素, 对角元素)`。

和 Householder 反射的对比：

| | Givens rotation | Householder 反射 |
|---|---|---|
| 每步操作 | 旋转 2 个维度，消去 1 个元素 | 反射整列，消去整列下三角 |
| 适合场景 | 稀疏矩阵、并行化 | 稠密矩阵、通用 |
| 计算量 | 多次操作，每次便宜 | 少次操作，每次较贵 |

numpy 的 `np.linalg.qr` 默认用 Householder。Givens 在 GPU 并行和稀疏场景更有优势。

### 2.4 RoPE 的分块对角结构

RoPE 不是用一个 Givens rotation 消元素，而是**把多个不重叠的 Givens rotation 合并为一个分块对角矩阵**：

```
         ┌ Rot(θ₀)                    ┐
         │        Rot(θ₁)             │
R(m) =   │              Rot(θ₂)       │     ← 48 个 2×2 旋转块
         │                    ...     │        对角线上，互不干扰
         └                    Rot(θ₄₇)┘
```

和 QR 分解中 Givens 的区别：

| | QR 分解中的 Givens | RoPE 中的 Givens |
|---|---|---|
| 目的 | 消去矩阵元素 | 编码位置信息 |
| 使用方式 | **串行**，逐个作用 | **并行**，不重叠的对同时旋转 |
| 旋转角度 | 由要消去的元素值决定 | 由 token 位置和频率决定 |
| 维度配对 | 按需选择任意 (i,j) 对 | 固定相邻配对 (0,1), (2,3), ... |

**线性代数定理**：任何偶数维的旋转矩阵（SO(n) 中的元素）都可以通过选择合适的基底，分解为分块对角形式——n/2 个互相正交的二维平面，每个平面上独立旋转。

RoPE 直接用相邻维度 (0,1), (2,3), ... 作为这些平面，这是最简单的选择。

### 2.5 为什么分块对角对计算有利

如果构造完整的 96×96 矩阵做矩阵乘：

```
计算量: 96 × 96 = 9216 次乘法
存储: 96 × 96 = 9216 个参数
```

分块对角矩阵每对只需 4 次乘法 + 2 次加法，48 对 = 288 次运算。

代码里更进一步，展开旋转公式为**逐元素运算**：

```python
# 二维旋转展开:
# q0' = q0·cosθ - q1·sinθ
# q1' = q0·sinθ + q1·cosθ
#
# 所有对一起做:
q_embed = q * cos + rotate_half(q) * sin
```

全是逐元素乘法和加法，GPU 上极快，不需要构造任何矩阵。
