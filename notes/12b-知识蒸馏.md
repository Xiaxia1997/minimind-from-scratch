## 动机：Hard Label vs Soft Label

SFT 用**人标注的 ground truth** 训练模型。Label 是 one-hot 的——正确答案位置为 1，其他全是 0。这叫 **hard label**：

```
问题: "中国的首都是？"
hard label (one-hot):
  北京: 1.00
  上海: 0.00
  南京: 0.00
  广州: 0.00
  其他6396个token: 0.00
```

Hard label 只说"北京是对的"，没有任何其他信息。但一个训好的大模型（teacher）的概率分布包含更多信息：

```
teacher 的 soft label (概率分布):
  北京: 0.70   ← 最可能
  上海: 0.15   ← 也是大城市，有一定相关性
  南京: 0.08   ← 也是省会，有一点相关
  广州: 0.04   ← 类似
  天津: 0.02
  ...其他: 0.01
```

这个概率分布告诉 student 模型："上海和南京虽然不是答案，但和北京有某种相似性——它们都是中国大城市"。这种从概率分布中泄露出来的类间关系信息，Hinton (2015) 称为**暗知识（dark knowledge）**。

**一句话**：hard label 只传递"正确答案是什么"，soft label 额外传递了"各个选项之间的相似关系"。student 从 soft label 学到的信息量 > hard label。

### MiniMind 的蒸馏场景

MiniMind 支持两种蒸馏配置：

```
场景 1: MoE 模型（teacher） → Dense 模型（student）
  teacher: hidden_size=768, use_moe=True   → 参数量更大（多个 expert）
  student: hidden_size=768, use_moe=False  → 参数量更小（单个 FFN）

场景 2: 大 hidden_size（teacher） → 小 hidden_size（student）
  teacher: hidden_size=1024  → 更大的隐层
  student: hidden_size=768   → 更小的隐层
```

两种场景的蒸馏流程完全一样——teacher 提供 soft label，student 去拟合。

## 蒸馏 Loss

### 核心公式

蒸馏 loss 用 KL 散度衡量 student 和 teacher 概率分布的差异：

$$L_{\text{distill}} = T^2 \cdot D_{\text{KL}}\big(\text{student}_T \,\|\, \text{teacher}_T\big)$$

其中 $T$ 是温度（temperature），下标 $_T$ 表示用温度 $T$ 做 softmax。

展开成代码：

```python
def distillation_loss(student_logits, teacher_logits, temperature=1.0):
    # teacher 用高温 softmax 产生更平滑的概率分布
    # .detach() 阻止梯度流入 teacher（teacher 不更新）
    teacher_probs = F.softmax(teacher_logits / temperature, dim=-1).detach()

    # student 用相同的温度做 log_softmax
    student_log_probs = F.log_softmax(student_logits / temperature, dim=-1)

    # KL 散度：student 去拟合 teacher 的分布
    # KL(P||Q) = Σ P(x) * log(P(x)/Q(x)) = Σ P(x) * [log P(x) - log Q(x)]
    # F.kl_div 接收 log Q 和 P，内部计算 P * (log P - log Q)
    kl = F.kl_div(student_log_probs, teacher_probs, reduction='batchmean')

    # temperature² 补偿（下面详解）
    return (temperature ** 2) * kl
```

### 为什么要乘 $T^2$

高温 softmax 的梯度比标准 softmax 小了 $1/T$ 倍（因为 logits 除以了 $T$，链式法则乘以 $1/T$）。这意味着蒸馏 loss 的梯度被 $1/T$ 缩小了。乘以 $T^2$ 是为了补偿这个缩小，让蒸馏 loss 和 CE loss 的梯度量级可比。

用数字感受：$T=1.5$ 时，不补偿的梯度只有 $T=1.0$ 时的 $1/1.5 \approx 0.67$，乘以 $1.5^2 = 2.25$ 后恢复到合理量级。

### Temperature 的作用

$T$ 控制 softmax 输出分布的"平滑度"：

```
logits = [5.0, 3.0, 1.0]

T=1.0 (标准 softmax):
  softmax = [0.844, 0.114, 0.042]   ← 集中：第一个占 84%

T=1.5:
  softmax = [0.679, 0.198, 0.123]   ← 更平：暗知识更明显

T=3.0:
  softmax = [0.506, 0.307, 0.187]   ← 很平：几乎均匀

T→∞:
  softmax → [0.333, 0.333, 0.333]   ← 完全均匀，丢失信息
```

$T$ 越高，分布越平滑，类间关系越明显——"上海和南京也有一定概率"这种暗知识被放大了。但太高（如 $T=5$）分布趋于均匀，暗知识反而被稀释。MiniMind 默认 $T=1.5$，业界常用 $T=1.0 \sim 2.0$。

### 总 Loss = $\alpha \cdot L_{\text{CE}} + (1 - \alpha) \cdot L_{\text{distill}}$

两个 loss 的加权混合：

- $L_{\text{CE}}$：交叉熵 loss，拟合 ground truth hard label
- $L_{\text{distill}}$：KL 散度 loss，拟合 teacher 的 soft label
- $\alpha = 0.5$（MiniMind 默认）：两者各占一半权重

```
为什么需要两个 loss？

只有 CE（α=1）: 和普通 SFT 一样，没有用到 teacher 的知识
只有 KL（α=0）: 完全忽略 ground truth，student 只模仿 teacher
              如果 teacher 在某些样本上犯错，student 也跟着犯错
混合（α=0.5）: ground truth 提供正确方向，teacher 补充类间关系
              两者互补——ground truth 纠正 teacher 的错误
                        teacher 提供 ground truth 没有的暗知识
```

## 完整训练流程

蒸馏训练的流程和 SFT 几乎一样，区别只有两点：
1. 多了一个 teacher 模型（冻结权重，只做推理）
2. loss 从纯 CE 变成 CE + KL 混合

```
一个训练 step:

① teacher.eval() + requires_grad_(False)  ← 冻结，全程不更新
② input_ids → student → student_logits    ← student 前向
③ input_ids → teacher → teacher_logits    ← teacher 前向（no_grad，不存计算图）
④ CE_loss = cross_entropy(student_logits, labels)
⑤ KL_loss = distillation_loss(student_logits, teacher_logits, T=1.5)
⑥ total_loss = α * CE_loss + (1-α) * KL_loss
⑦ total_loss.backward()  → 只有 student 的参数收到梯度
⑧ optimizer.step()       → 只更新 student
```

**显存注意**：GPU 上同时放两个模型。teacher 虽然冻结（不存梯度和优化器状态），但参数本身要占显存。MiniMind 的 teacher（MoE，~100M）和 student（Dense，~64M）加起来才 ~160M 参数，4060 轻松放下。大模型蒸馏时 teacher 可能需要单独一张卡，用分布式方案处理。

### vocab_size 对齐

当 teacher 和 student 的 vocab_size 不同时（比如 teacher 用更大的词表），需要截断 teacher 的 logits 到 student 的 vocab_size：

```python
# teacher_logits: [..., teacher_vocab_size]
# student_logits: [..., student_vocab_size]
vocab_size_student = student_logits.size(-1)
teacher_logits = teacher_logits[..., :vocab_size_student]
# 截断后两者最后一维对齐，才能算 KL 散度
```

MiniMind 的 teacher 和 student 共用同一个 tokenizer（vocab_size=6400），但代码里保留了这个截断逻辑以兼容不同配置。

### loss_mask 的处理

和 SFT 一样，蒸馏只对有效 token 计算 loss（跳过 padding 位置）。上游代码用 `loss_mask` 在计算 KL 之前过滤掉 padding token：

```python
# loss_mask: [batch, seq_len-1]，有效 token=1，padding=0
loss_mask_flat = loss_mask.view(-1)     # 展平成 [batch * (seq_len-1)]

# 只选有效 token 的 logits 来算 KL
# loss_mask_flat == 1 的位置是有效 token
distill_loss = distillation_loss(
    student_logits.view(-1, vocab_size)[loss_mask_flat == 1],
    teacher_logits.view(-1, vocab_size)[loss_mask_flat == 1],
    temperature=temperature
)
```

## 完整实现

> 以下代码写到 `scratch/trainer/train_distillation.py`（新建文件）。保留核心算法（蒸馏 loss、双模型前向、$\alpha$ 混合），省略分布式训练、wandb 日志等工程细节。

```python
# ---- Chapter 12b: 知识蒸馏训练脚本 ----
# 写到: scratch/trainer/train_distillation.py
#
# 依赖:
#   - scratch/model/model_minimind.py (Chapter 08 完整模型)
#   - scratch/dataset/lm_dataset.py   (Chapter 12 SFTDataset)
#   - scratch/trainer/trainer_utils.py (Chapter 09 get_lr / Logger)

import os, sys, time, argparse
import torch
import torch.nn.functional as F
from torch import optim
from torch.utils.data import DataLoader
from contextlib import nullcontext

sys.path.append(os.path.abspath(os.path.join(os.path.dirname(__file__), '../..')))
from model.model_minimind import MiniMindConfig, MiniMindForCausalLM
from dataset.lm_dataset import SFTDataset
from transformers import AutoTokenizer
from trainer_utils import get_lr, Logger


# ============================================================
# 蒸馏 Loss
# ============================================================

def distillation_loss(student_logits, teacher_logits, temperature=1.0):
    """KL 散度蒸馏 loss，student 拟合 teacher 的 soft label"""
    # teacher 的 soft label：高温 softmax → 更平滑的概率分布
    # .detach() 阻止梯度流入 teacher（teacher 不更新）
    # with torch.no_grad() 在调用侧已经包好了，这里 detach 是双重保险
    teacher_probs = F.softmax(teacher_logits / temperature, dim=-1).detach()

    # student 的 log 概率：和 teacher 用相同温度
    student_log_probs = F.log_softmax(student_logits / temperature, dim=-1)

    # KL 散度：P * (log P - log Q)
    # F.kl_div 接收 (log Q, P)，即 (student_log_probs, teacher_probs)
    # reduction='batchmean'：先求和再除以 batch size
    kl = F.kl_div(student_log_probs, teacher_probs, reduction='batchmean')

    # T² 补偿：高温 softmax 使梯度缩小 1/T，乘 T² 补回来
    return (temperature ** 2) * kl


# ============================================================
# 训练一个 epoch
# ============================================================

def train_epoch(model, teacher_model, loader, optimizer, scaler, autocast_ctx,
                epoch, lm_config_student, args):
    model.train()
    # teacher 全程冻结：eval 模式 + 关闭梯度
    if teacher_model is not None:
        teacher_model.eval()
        teacher_model.requires_grad_(False)

    iters = len(loader)
    start_time = time.time()

    for step, (input_ids, labels) in enumerate(loader, start=1):
        input_ids = input_ids.to(args.device)  # [B, S]
        labels = labels.to(args.device)         # [B, S]

        # loss_mask: 标记哪些位置是有效 token（非 -100）
        # labels[..., 1:] 是移位后的 label，和 logits[..., :-1] 对齐
        loss_mask = (labels[..., 1:] != -100).float()  # [B, S-1]

        # LR 调度
        lr = get_lr(epoch * iters + step, args.epochs * iters, args.learning_rate)
        for param_group in optimizer.param_groups:
            param_group['lr'] = lr

        # ---- student 前向 ----
        with autocast_ctx:
            res = model(input_ids)
            # 移位：logits[..., :-1] 对应 labels[..., 1:]
            student_logits = res.logits[..., :-1, :].contiguous()  # [B, S-1, V]

        # ---- teacher 前向（不存计算图，省显存）----
        if teacher_model is not None:
            with torch.no_grad():
                teacher_logits = teacher_model(input_ids).logits[..., :-1, :].contiguous()
                # vocab_size 对齐：teacher 可能有更大的词表
                vocab_size_student = student_logits.size(-1)
                teacher_logits = teacher_logits[..., :vocab_size_student]

        # ---- 计算 Loss ----

        # 1) CE Loss：student vs ground truth
        shift_labels = labels[..., 1:].contiguous()  # [B, S-1]
        loss_mask_flat = loss_mask.view(-1)           # [B*(S-1)]
        ce_loss = F.cross_entropy(
            student_logits.view(-1, student_logits.size(-1)),  # [B*(S-1), V]
            shift_labels.view(-1),                              # [B*(S-1)]
            ignore_index=-100,
            reduction='none'                                    # 逐 token loss
        )
        # 手动 mask：只对有效 token 求平均
        ce_loss = torch.sum(ce_loss * loss_mask_flat) / (loss_mask_flat.sum() + 1e-8)
        # MoE 辅助 loss
        if lm_config_student.use_moe:
            ce_loss = ce_loss + res.aux_loss

        # 2) 蒸馏 Loss：student vs teacher
        if teacher_model is not None:
            # 只在有效 token 上算 KL
            # loss_mask_flat == 1 的位置是有效 token
            distill_loss_val = distillation_loss(
                student_logits.view(-1, student_logits.size(-1))[loss_mask_flat == 1],
                teacher_logits.view(-1, teacher_logits.size(-1))[loss_mask_flat == 1],
                temperature=args.temperature
            )
        else:
            distill_loss_val = torch.tensor(0.0, device=args.device)

        # 3) 总 Loss = α * CE + (1-α) * KL
        loss = (args.alpha * ce_loss + (1 - args.alpha) * distill_loss_val)
        loss = loss / args.accumulation_steps

        # ---- 反向 + 更新 ----
        scaler.scale(loss).backward()

        if step % args.accumulation_steps == 0:
            scaler.unscale_(optimizer)
            torch.nn.utils.clip_grad_norm_(model.parameters(), args.grad_clip)
            scaler.step(optimizer)
            scaler.update()
            optimizer.zero_grad(set_to_none=True)

        # ---- 日志 ----
        if step % args.log_interval == 0 or step == iters:
            real_loss = loss.item() * args.accumulation_steps
            eta_min = (time.time() - start_time) / step * (iters - step) // 60
            Logger(f'Epoch:[{epoch+1}/{args.epochs}]({step}/{iters}) '
                   f'loss:{real_loss:.4f} ce:{ce_loss.item():.4f} '
                   f'distill:{distill_loss_val.item():.4f} lr:{lr:.8f} '
                   f'eta:{eta_min:.1f}min')

        # ---- 保存 ----
        if step % args.save_interval == 0 or step == iters:
            model.eval()
            moe_suffix = '_moe' if lm_config_student.use_moe else ''
            ckp = f'{args.save_dir}/full_dist_{lm_config_student.hidden_size}{moe_suffix}.pth'
            torch.save(
                {k: v.half().cpu() for k, v in model.state_dict().items()},
                ckp
            )
            model.train()

        del input_ids, labels, loss_mask, res, student_logits, ce_loss, distill_loss_val, loss

    # epoch 末尾：处理残余累积梯度
    if iters % args.accumulation_steps != 0:
        scaler.unscale_(optimizer)
        torch.nn.utils.clip_grad_norm_(model.parameters(), args.grad_clip)
        scaler.step(optimizer)
        scaler.update()
        optimizer.zero_grad(set_to_none=True)


# ============================================================
# 主函数
# ============================================================

if __name__ == "__main__":
    parser = argparse.ArgumentParser(description="MiniMind Knowledge Distillation")
    parser.add_argument("--save_dir", default="../../out")
    parser.add_argument("--epochs", type=int, default=6)
    parser.add_argument("--batch_size", type=int, default=32)
    parser.add_argument("--learning_rate", type=float, default=5e-6)
    parser.add_argument("--device", default="cuda:0" if torch.cuda.is_available() else "cpu")
    parser.add_argument("--dtype", default="bfloat16")
    parser.add_argument("--accumulation_steps", type=int, default=1)
    parser.add_argument("--grad_clip", type=float, default=1.0)
    parser.add_argument("--log_interval", type=int, default=100)
    parser.add_argument("--save_interval", type=int, default=100)
    parser.add_argument("--max_seq_len", type=int, default=340)
    parser.add_argument("--data_path", default="../../dataset/sft_t2t_mini.jsonl")
    # student 配置
    parser.add_argument("--student_hidden_size", type=int, default=768)
    parser.add_argument("--student_num_layers", type=int, default=8)
    parser.add_argument("--student_use_moe", type=int, default=0, choices=[0, 1])
    parser.add_argument("--from_student_weight", default="full_sft")
    # teacher 配置
    parser.add_argument("--teacher_hidden_size", type=int, default=768)
    parser.add_argument("--teacher_num_layers", type=int, default=8)
    parser.add_argument("--teacher_use_moe", type=int, default=1, choices=[0, 1])
    parser.add_argument("--from_teacher_weight", default="full_sft")
    # 蒸馏超参
    parser.add_argument("--alpha", type=float, default=0.5,
                        help="CE 权重，总 loss = alpha*CE + (1-alpha)*KL")
    parser.add_argument("--temperature", type=float, default=1.5,
                        help="蒸馏温度（推荐 1.0-2.0）")
    args = parser.parse_args()

    os.makedirs(args.save_dir, exist_ok=True)

    # ---- 1. student 模型 ----
    lm_config_student = MiniMindConfig(
        hidden_size=args.student_hidden_size,
        num_hidden_layers=args.student_num_layers,
        use_moe=bool(args.student_use_moe),
    )
    model = MiniMindForCausalLM(lm_config_student).to(args.device)
    tokenizer = AutoTokenizer.from_pretrained('../../model')
    Logger(f'Student params: {sum(p.numel() for p in model.parameters()) / 1e6:.3f}M')

    # ---- 2. teacher 模型（冻结）----
    lm_config_teacher = MiniMindConfig(
        hidden_size=args.teacher_hidden_size,
        num_hidden_layers=args.teacher_num_layers,
        use_moe=bool(args.teacher_use_moe),
    )
    teacher_model = MiniMindForCausalLM(lm_config_teacher).to(args.device)
    teacher_model.eval()
    teacher_model.requires_grad_(False)
    Logger(f'Teacher params: {sum(p.numel() for p in teacher_model.parameters()) / 1e6:.3f}M')

    # ---- 3. 数据 + 优化器 ----
    train_ds = SFTDataset(args.data_path, tokenizer, max_length=args.max_seq_len)
    loader = DataLoader(train_ds, batch_size=args.batch_size, shuffle=True,
                        num_workers=4, pin_memory=True, drop_last=True)
    optimizer = optim.AdamW(model.parameters(), lr=args.learning_rate)

    # ---- 4. 混合精度 ----
    dtype = torch.bfloat16 if args.dtype == "bfloat16" else torch.float16
    autocast_ctx = (nullcontext() if "cpu" in args.device
                    else torch.amp.autocast('cuda', dtype=dtype))
    scaler = torch.amp.GradScaler(enabled=(args.dtype == 'float16'))

    # ---- 5. 训练 ----
    for epoch in range(args.epochs):
        train_epoch(model, teacher_model, loader, optimizer, scaler, autocast_ctx,
                    epoch, lm_config_student, args)
```

## 业界对比

| 特性 | MiniMind 蒸馏 | DistilBERT (Sanh 2019) | Gemma 2 (Google 2024) |
|------|-------------|----------------------|----------------------|
| 蒸馏方式 | logits KL（词表级） | logits KL + hidden states MSE（隐层对齐） | 在线蒸馏（teacher 和 student 同时训） |
| teacher | MoE 或大 hidden_size | BERT-base | 更大的 Gemma 模型 |
| $\alpha$ | 0.5 | 0.5 | 未公开 |
| $T$ | 1.5 | 2.0 | 未公开 |
| 数据 | SFT 数据 | 预训练数据 | 预训练 + 合成数据 |
| 隐层对齐 | 无（只对齐 logits） | 有（hidden states MSE） | 有 |
| 蒸馏阶段 | SFT 后 | 预训练阶段 | 预训练阶段 |

MiniMind 只做了最基础的 logits-level KL 蒸馏。业界更常见的做法是加上**隐层对齐**（让 student 的中间层表示也接近 teacher），但这需要 teacher 和 student 的 hidden_size 匹配或加投影层。

### 蒸馏 vs 直接训练小模型

蒸馏有价值的前提是 **teacher 比 student 强**。如果 teacher 本身很弱，soft label 里的暗知识质量也差，蒸馏不如直接训 student。

业界共识：蒸馏在小模型（<1B）上效果最好——小模型容量有限，从 teacher 的 soft label 中学到的信息比从 hard label 中更丰富。大模型（7B+）自身容量足够，蒸馏的边际收益递减。

## 面试话术

> "知识蒸馏我完整实现过，核心就是让 student 同时拟合两个目标：ground truth 的 hard label（CE loss）和 teacher 的 soft label（KL loss），加权混合 $\alpha=0.5$。soft label 包含暗知识——比如'北京'是答案时 teacher 的概率分布会给'上海'一个较高概率，这种类间关系是 hard label 没有的。温度 $T=1.5$ 让 teacher 的分布更平滑，暴露更多暗知识；乘 $T^2$ 补偿高温导致的梯度缩小。MiniMind 的场景是 MoE 蒸馏 Dense，teacher 参数更多但训练好，student 参数少但能从 teacher 的分布中学到更多信息。"
