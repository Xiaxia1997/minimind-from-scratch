## Priority 1: 答错 / 混淆（必须纠正，面试踩坑点）

### 1.1 梯度累积 vs 梯度检查点 搞混了

- **你的回答**：梯度累积 = 间隔几层存激活值，需要的时候重算 → 这其实是**梯度检查点**的定义
- **正确区分**：
  - **梯度累积**（Gradient Accumulation）：多个 micro-batch 的梯度**加起来**，攒够了再做一次 optimizer.step()。目的是用小显存模拟大 batch size。跟激活值无关。
  - **梯度检查点**（Gradient Checkpointing）：前向时只存部分层的激活值，反向时重新算。时间换空间。
- **复习**：notes/09-训练基础.md（梯度累积部分）、notes/11-预训练.md（训练循环实现）

### 1.2 GQA 方向说反了

- **你的回答**："一个 group 的 Q 对应着多个 KV"
- **正确**：反过来——**多个 Q 头共享一组 KV 头**。GQA 的 "G" 是把 Q 头分成若干组，每组共享一对 K/V。所以 KV 头数 < Q 头数，KV Cache 变小。
  - MHA：每个 Q 头配一对独立的 K/V（KV 头数 = Q 头数）
  - MQA：所有 Q 头共享**同一对** K/V（KV 头数 = 1）
  - GQA：Q 头分 g 组，每组共享一对 K/V（KV 头数 = g）
- **复习**：notes/04-Attention.md

### 1.3 Q 和 K 为什么用不同权重矩阵——解释有误

- **你的回答**：Q 是用户问题，K 是之前的元素
- **正确**：在 **Self-Attention** 中，Q、K、V 都来自**同一个输入**。使用不同权重矩阵的原因是：如果 Q=K（同一个投影），attention 矩阵 QK^T 会变成对称矩阵，限制了模型的表达能力。不同的 W_Q 和 W_K 允许学习**非对称**的注意力模式（"我关注你"不等于"你关注我"）。
- **复习**：notes/04-Attention.md

### 1.4 Softmax 数值稳定性——答成了混合精度

- **你的回答**：用 BF16 或者先乘一个大数
- **正确**：标准做法是 **safe softmax**——在计算 exp() 之前，先减去当前行的最大值 max(x)。这样 exp(x - max) 的最大值为 1，不会溢出。跟 BF16/FP16 是两个维度的问题。
- **复习**：notes/04-Attention.md（Softmax 数值稳定性部分）

### 1.5 PPL 和交叉熵的关系说不清

- **你的回答**：正相关，然后又说不确定
- **正确**：PPL = exp(cross_entropy_loss)，是**指数关系**。交叉熵越低 → PPL 越低 → 模型越好。PPL 的直觉含义是"模型在每个位置平均犹豫几个候选词"，PPL=10 意味着模型平均在 10 个词之间犹豫。
- **复习**：notes/09-训练基础.md

### 1.6 混合精度的显存节省说法有误

- **你的回答**："不考虑激活值的话，显存没有节约"
- **正确**：混合精度**确实**节省显存。前向和反向的激活值从 FP32(4B) 变成 BF16(2B)，激活值显存减半。模型参数多存了一份 BF16 副本，但激活值在总显存中占大头（尤其长序列），所以整体是省的。
- **复习**：notes/11-预训练.md（混合精度部分）

### 2.2 RoPE 核心机制（Ch 5）—— 几乎全空

RoPE 是**每家都问**的基础题。你知道它是乘性的、跟相对位置有关，但具体机制说不出来。

**必须掌握**：
- RoPE = 在 Q/K 向量上做**二维旋转**，旋转角度由位置决定
- 作用在 Q 和 K 上，不作用在 V 上
- QK 点积自然只依赖相对位置差（旋转角度相减）
- 远程衰减：远距离的 token pair 点积趋向零
- ALiBi 的对比差异

**复习**：notes/03-RoPE.md

### 2.4 优化器公式（Ch 9）—— 知道概念但说不出公式

面试中被问到 AdamW，至少要能写出更新公式。

**必须掌握**：
- Adam：m = β1·m + (1-β1)·g，v = β2·v + (1-β2)·g²，θ -= lr · m̂/(√v̂ + ε)
- AdamW 的区别：weight decay 从 L2 正则化中解耦，直接在参数上减 λ·θ
- 一阶动量 = 梯度的指数移动平均（方向）；二阶动量 = 梯度平方的指数移动平均（步长自适应）

**复习**：notes/09-训练基础.md

### 2.5 激活函数公式（Ch 6）—— 只记得 ReLU

SwiGLU 公式是常见考点。

**必须掌握**：
- SwiGLU(x) = Swish(x · W_gate) ⊙ (x · W_up)，然后 · W_down
- Swish(x) = x · σ(βx)，β=1 时就是 SiLU
- 为什么有三个线性层（gate_proj, up_proj, down_proj）

**复习**：notes/05-FeedForward&激活函数.md

### 2.6 知识蒸馏机制（Ch 19 蒸馏部分）

**必须掌握**：
- Temperature：T 越高 → softmax 越平滑 → 暴露更多"暗知识"
- 蒸馏 loss = α·KL(soft_student || soft_teacher) + (1-α)·CE(student, hard_label)
- T² 补偿：因为除以 T 让 logits 变小，梯度也变小，乘 T² 补偿回来

**复习**：notes/12b-知识蒸馏.md

### 2.7 Causal Attention 满秩问题（Q4）

这是区分 Decoder-only 优于 Encoder-only 的核心论点。

**正确答案**：下三角矩阵天然满秩（对角线全为正值，行列式非零）。双向 Attention 的 softmax(QK^T) 趋向低秩——因为所有 token 都能互相看到，attention 分布容易坍缩成几个相似的模式。满秩 = 每个 token 的注意力分布都不同 = 表达能力更强。

**复习**：notes/04-Attention.md
