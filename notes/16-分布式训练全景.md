## 一句话总结

数据并行复制模型到多卡各算各的，模型并行把模型切开分给多卡，流水线并行按层切开串联。大模型训练通常三者组合（3D 并行）。

## 数据并行（Data Parallelism）

### DDP（DistributedDataParallel）— MiniMind 用的

```
GPU 0: 完整模型副本 + 数据分片 A → 梯度 A
GPU 1: 完整模型副本 + 数据分片 B → 梯度 B
                ↓ AllReduce（求平均）
GPU 0: 平均梯度 → 更新权重
GPU 1: 平均梯度 → 更新权重（两卡权重保持同步）
```

显存占用：每卡 = 完整模型参数 + 优化器状态 + 梯度 + 激活值
- 优点：实现简单，通信开销小（只需 AllReduce 梯度）
- 缺点：每卡都存完整模型，显存浪费大

#### MiniMind 中的 DDP 实现

```python
# trainer/train_pretrain.py:110-111, 154
local_rank = init_distributed_mode()          # 初始化 NCCL
model = DistributedDataParallel(model, device_ids=[local_rank])  # 包装模型

# trainer/trainer_utils.py:44-51
def init_distributed_mode():
    dist.init_process_group(backend="nccl")   # NVIDIA GPU 间通信
    local_rank = int(os.environ["LOCAL_RANK"])
    torch.cuda.set_device(local_rank)
    return local_rank
```

启动命令：`torchrun --nproc_per_node=2 train_pretrain.py`

### ZeRO（Zero Redundancy Optimizer）— DeepSpeed 核心

DDP 的问题：4 张卡各存一份完整的 optimizer states / gradients / parameters，3/4 是冗余。

ZeRO 分三个阶段逐步消除冗余：

| 阶段 | 切分什么 | 显存节省 | 通信增加 |
|------|---------|---------|---------|
| ZeRO-1 | Optimizer States（Adam 的 m, v） | ~4x | 无额外 |
| ZeRO-2 | + Gradients | ~8x | 少量 |
| ZeRO-3 | + Parameters（模型参数也切分） | ~N x（N=GPU数） | 前向/反向都要 AllGather |

```
ZeRO-1 示例（4 卡）:
GPU 0: 完整参数 + 完整梯度 + 1/4 optimizer states
GPU 1: 完整参数 + 完整梯度 + 1/4 optimizer states
GPU 2: 完整参数 + 完整梯度 + 1/4 optimizer states
GPU 3: 完整参数 + 完整梯度 + 1/4 optimizer states
→ 每卡 optimizer 显存从 O 减到 O/4
```

```
ZeRO-3 示例（4 卡）:
GPU 0: 1/4 参数 + 1/4 梯度 + 1/4 optimizer states
       前向时 AllGather 收集完整参数 → 计算 → 释放
       反向时 AllGather 收集完整参数 → 计算梯度 → ReduceScatter
→ 通信多了但显存极大减少，能训更大的模型
```

### FSDP（Fully Sharded Data Parallel）— PyTorch 原生的 ZeRO-3

和 DeepSpeed ZeRO-3 原理相同，但是 PyTorch 原生实现，不需要额外框架。
LLaMA 训练用的就是 FSDP。

## 模型并行（Model Parallelism）

### Tensor Parallel（张量并行）— Megatron-LM

把单个算子内部的矩阵乘法切分到多卡：

```
Linear: Y = XA

列切分:  A = [A₁ | A₂]
GPU 0: Y₁ = X × A₁     # 各算一半列
GPU 1: Y₂ = X × A₂
Y = [Y₁ | Y₂]          # concat 结果

行切分:  A = [A₁]       
             [A₂]
GPU 0: Y₁ = X₁ × A₁   # 各算一半行
GPU 1: Y₂ = X₂ × A₂
Y = Y₁ + Y₂            # AllReduce 求和
```

MiniMind 的 Attention 中 Q/K/V/O 四个 Linear 可以这样切：
- Q/K/V 按 head 维度切（列切分）→ 每卡负责部分 head
- O 按输入维度切（行切分）→ AllReduce 合并

优点：单层计算和显存都分摊
缺点：需要在每层做通信（AllReduce / AllGather），通信密集

### Pipeline Parallel（流水线并行）

按层切分模型，不同层放不同卡：

```
GPU 0: Layer 0-3 （前 4 层）
GPU 1: Layer 4-7 （后 4 层）

朴素版（GPU 利用率低）:
时间 →  [GPU0: 前向 L0-3] → [GPU1: 前向 L4-7] → [GPU1: 反向 L4-7] → [GPU0: 反向 L0-3]
        GPU1 空闲          GPU0 空闲            GPU0 空闲           GPU1 空闲
        ← 大量 bubble →

GPipe（微批次流水线）:
把 batch 拆成 4 个 micro-batch，交错执行：
GPU0: [F₁][F₂][F₃][F₄]         [B₄][B₃][B₂][B₁]
GPU1:     [F₁][F₂][F₃][F₄][B₄][B₃][B₂][B₁]
→ bubble 大幅减少
```

优点：每卡只存部分层，显存按层数线性减少
缺点：有 bubble（GPU 空闲时间），micro-batch 越多 bubble 越小

## 3D 并行（业界大模型标配）

```
3D 并行 = Data Parallel × Tensor Parallel × Pipeline Parallel

示例：64 卡训 175B 模型
- Pipeline Parallel = 4（模型按层分 4 段）
- Tensor Parallel = 4（每段内的算子分 4 卡）
- Data Parallel = 4（4 组数据并行）
- 4 × 4 × 4 = 64 卡
```

| 并行方式 | 切什么 | 通信模式 | 适用场景 |
|---------|--------|---------|---------|
| Data Parallel | 数据 | AllReduce 梯度 | 模型放得下一卡 |
| ZeRO | 优化器/梯度/参数 | AllGather + ReduceScatter | 模型勉强放一卡 |
| Tensor Parallel | 算子内矩阵 | AllReduce（每层） | 模型放不下一卡，节点内高带宽 |
| Pipeline Parallel | 层 | 点对点传激活值 | 跨节点，带宽低 |

## 显存占用分析（面试必背）

训练 1B 参数模型，FP32：

```
模型参数:     1B × 4 bytes = 4 GB
梯度:         1B × 4 bytes = 4 GB
Adam states:  1B × 8 bytes = 8 GB（m + v 各 4 bytes）
激活值:       取决于 batch size 和序列长度
──────────────────────────────────
最低显存 ≈ 16 GB + 激活值

混合精度:
模型参数:     1B × 2 bytes = 2 GB（bf16）
梯度:         1B × 2 bytes = 2 GB（bf16）
Master weights: 1B × 4 bytes = 4 GB（FP32，optimizer 持有）
Adam states:  1B × 8 bytes = 8 GB
──────────────────────────────────
最低显存 ≈ 16 GB + 激活值（混合精度主要省在激活值上）
```

## 面试话术

> 分布式训练有三种基本并行策略：
> 数据并行（DDP）把数据分片，每卡持有完整模型，AllReduce 同步梯度——MiniMind 用的就是这种；
> ZeRO 是 DDP 的优化，逐步切分 optimizer states、gradients、parameters 消除冗余显存；
> 模型并行分两种：Tensor Parallel 在算子内部切矩阵（Megatron-LM 的做法），
> Pipeline Parallel 按层切模型，用微批次流水线减少 bubble。
> 业界训大模型通常用 3D 并行组合三者。
> 在 MiniMind 项目里我实操了 DDP，理解了 AllReduce 通信和 DistributedSampler 的配合，
> 对 ZeRO 和 3D 并行的原理了解但没有亲手跑过。
